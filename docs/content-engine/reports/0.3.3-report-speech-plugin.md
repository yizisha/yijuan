## 实现范围

- 基础 APK 仅保留接口、连接适配器、入口和管理面板；实际系统 TTS 调用、分段播放和原生控制面板在独立插件中。APK DEX 的类定义与 ZIP 内容已检查：无 SystemSpeechPlugin 实现或 .yjp；插件也没有重复打包共享接口。
- 新增 :plugin-api 与 :plugin:tts，沿用已有 Android/Java 工具，无应用第三方依赖、账号或新云服务。系统 TTS 本来不自带模型，本插件也不包含语音模型；音色、语言和离线能力取决于手机系统引擎。
- 下载限制 HTTPS（每次跳转重新检查）、连接/读取超时、2 MiB 输入与解压上限、下载字节进度和取消；支持本地导入、更新、移除及重新启用。
- 原始描述和 DEX 一起用 SHA256withRSA 签名；只信任当前基础 APK 签名证书的公钥，限定插件 ID、API v1、入口和版本格式，拒绝额外/重复/缺失 ZIP 文件；校验通过后才创建代码加载器。
- 代码与归档放在本设备 noBackupFilesDir，执行文件先设为只读再写入；使用 AtomicFile 记录活动版本。失败更新保留旧指针和播放；重复导入相同包不打断播放；同版本不同构建按摘要刷新控件。
- 未安装时不初始化系统语音；退出阅读器、更新或移除时释放引擎，忽略旧实例的迟到回调；面板销毁时断开原生 View 引用。
- 第一版提供开始/暂停/继续、停止和语速；超过 3800 字的当前章节分段继续，避免拆开表情的 UTF-16 代理对。缺少系统语言数据时显示提示并禁用播放，不无限排队。
- 主程序原有起读位置换算保留：分页模式仍按原行为从当前章节开始。未新增自动跨章、听书定时关闭或自带语音模型。暂停续读依赖引擎范围回调，不支持该回调的引擎可能重读当前分段。
- 阅读器面板跟随阅读明暗状态；应用设置面板沿用应用主题。暖炭/柔金夜间色、两套主题、书架封面与排列保持原样；未修改数据库、备份 JSON、旧阅读设置键、分页与章节预加载。
