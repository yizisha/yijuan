## 问题与修改

### 书签定位

- 分页回调从实际排版片段取得章内 UTF-16 源偏移，书签不再把页下标伪装成文字偏移。保存、退出及恢复共用已确认的源锚点。
- 章节读序和数据库 `Chapter.index` 分开映射，修正跳号章节在兼容定位清单中找不到文档、退回第一章的问题。
- 跳转书签交给分页/滚动布局映射，源偏移不再直接作为页码。旧书签若残留另一章的 locator，按书签自己的章号和旧位置回退，标记近似，不修改原书签。
- 初始章的正文有时仅在 `currentChapter` 中，元数据列表仍为空正文；定位现在读取已加载正文。

### 反复出现的导入提示

- 提示事件先消费，再由独立的页面协程展示。离开页面中断提示时，返回不会重复显示。
- Activity 初始共享文件 URI 在书架 ViewModel 中只接收一次；返回书架不会再次导入。用户重新从文件选择器导入不受限制。

### 阅读时间

- 使用单调时钟，未开始的计时器不产生任何时间。前后台、锁屏和阅读页离开按生命周期暂停/结算，正文未就绪时不启动。
- 定期保存只消费增量，不重置当前页、部分页计数或空闲截止点。无操作最多计入 5 分钟，定期保存不能让闲置阅读器一直活跃。
- 长间隔后交互保留先前未保存的时间，亚秒尾数保留；退出时已消费的增量独立完成写入，避免页面协程取消后丢失。
- 仓库串行合并时间/页数增量，避免周期保存和退出保存并发读改写时互相覆盖。不改数据库 schema。
- **保留历史记录**：现有按日汇总数据无法推断真实阅读时长，不能自动还原已写入的 86 小时。没有清空、裁剪或篡改用户统计。

### Kokoro 试听与播放

- 中文/英文使用模型提供的词典，不强制非官方示例中的 `zh` espeak 覆盖；Kokoro 使用 4 个推理线程。
- 首段最多 24 个 UTF-16 单元，后续最多 60；原生分句回调直接写媒体音频，取消在句边界停止，避免必须等待整大段合成后才播放。
- 音频输出初始化检查、错误展示、准备/实际播放状态分开；纯标点和空白片段跳过。模型页增加试听状态、错误原因、停止按钮和媒体音量/蓝牙输出提示。
- 重选同一模型不反复销毁原生引擎。下载后的权重沿用，不要求重新下载。
- 原生验收发现 SDK 反射要求 `invoke(float[]): Integer`，Kotlin 合成匿名函数只有擦除签名时会触发 JNI 致命错误；改为显式 `SpeechPcmCallback`，加入反射签名用例和精确 R8 保留规则。中间失败包仅保留在 build 诊断目录。
- 官方 1.13.8 源码明确 `dictDir` 已不再使用，未把补字典目录作为修复。模型页无反馈、首段等待与特定手机完全静音不能混为同一已证明根因。
