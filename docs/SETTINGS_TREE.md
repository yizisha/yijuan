# 设置与导航结构（0.3.11）

## 主导航

固定为 **书架／统计／笔记／设置**，不受旧 `showContinueTab` 和 `showStatsTab` 字段控制。
书架首页直接显示书籍；继续阅读通过点击已有阅读记录的书籍进入，阅读历史归顶部更多菜单。书单、发现（OPDS）、添加到书单入口隐藏，原实现与数据保留。
阅读器隐藏主导航；设置子页选中设置，阅读历史选中书架；600dp 起沿用侧栏。

0.3.11：书架顶部更多增加“系列与卷序”，书籍详情提供同一管理面板。系列可命名、添加/移出、重命名、上下调整卷序；不改变分组或收藏。书架筛选后合并系列，面板可主动打开整套；到卷末提示下一卷，用户确认后进入。
PDF 复用目录、进度滑杆及上一页/下一页，保留原始版式，支持缩放与页码恢复；正文排版控件不改变 PDF 页面。详情显示文件大小，缺失文件显示未知。完整备份从本版包含 schema 12 系列字段，旧 schema 11 可恢复。

## 阅读面板与共享规则

阅读面板采用字体、排版、主题、翻页四个短下划线标签。字体标签集中字号、字体预设/更多字体、行距、段距、边距、色板和夜间；当前窗口亮度（可恢复系统）及字体导入默认折叠。
字体与排版复用应用设置中的 `FontPage` 和 `TypographyPage`；主题、翻页复用相同编辑组件。屏幕与护眼进入“更多阅读设置”，目标与提醒仅在应用设置中展示。
阅读控制栏顶部为返回、听书、添加书签、唯一更多菜单（全文搜索、书签、高亮与笔记、分享进度、阅读设置、专注模式）；底部为章节计数与阅读百分比、滑杆两侧的上一章／下一章（首尾禁用），以及目录、夜间／日间、亮度、设置。右下角重复更多面板已移除，完整设置由右上角阅读设置或底部设置入口进入。无文本的格式禁用听书。
目录、书签和笔记统一进入同一标签面板，分别打开对应标签；保留跳转、笔记编辑和删除确认。
高级编辑默认折叠，摘要展示当前值，非默认配置标记“已自定义”；折叠不会恢复默认值。
字体选择为菜单，导入及预览另行展开。翻页动画仅分页模式下显示。

正文标注默认细下划线，也可在阅读面板“主题”或应用设置“阅读 → 主题与背景”切换柔和高亮。
使用独立偏好 `annotation_display_style`；不更改旧标注类型、颜色、源范围或数据库；完整备份保存全部定位字段。

## 书籍文件位置

书籍详情的统计／目录／书签／笔记分组末尾增加“文件位置”。原文件来源、应用内阅读副本和另存副本分别显示；位置可选中或复制。
本地外部存储文档以父目录 URI 为系统文档浏览器的初始位置，避免第三方管理器只启动不定位。聊天应用 Android/data 共享文件没有父目录授权，明确说明并隐藏不可用跳转，保留复制/关联/另存；真实系统目录定位尚未验收。
新导入记录本设备原 URI；旧书可以手动关联原文件，只记录来源，不重新解析、不替换正文、不修改进度或笔记。ZIP 临时解压文件不冒充原始文件。
应用私有阅读副本不向其他应用暴露；“保存副本到本地”通过系统选择目标，写入成功后记录另存位置。来源及持久 URI 授权属于本设备，不随书籍 JSON 备份迁移。

`FlowPreferenceGroup` 统一分组容器；`FlowExpandableGroup` 统一折叠、摘要和状态；
`FlowChoiceChip`、`FlowSlider` 统一选择与滑杆；导航和详情共用标题规则。
应用设置与阅读控制界面使用完整主题色板，阅读面板/目录按阅读色板判断明暗并保留当前配色来源。
清简蓝的应用界面采用纯白底色、白色表面和中性灰容器；蓝色用于按钮与选中状态，不使用参考图外部的蓝色展示背景作为应用底色。
正文及阅读主题预览仍采用用户选择的阅读色板。清简蓝仅调整纸白为轻暖白；其他色板、自定义背景与现有夜间颜色保留。

主导航、阅读工具栏和主要操作采用 `FlowIcons` 共用细线矢量；选项保持 48dp 触控区域、32dp 视觉按钮，分类色块仅在清简蓝主题配色的浅色界面启用，动态/单色遵循其语义颜色。
笔记页提供笔记/划线标签、搜索和书籍筛选，编辑/删除/回原文收入卡片菜单，导出跟随标签。书架更多里的导入打开现有文件、ZIP、目录扫描设置入口面板。

## 书架筛选与收藏

- 主筛选栏：当前分组（默认“全部”）、未读、正在读、已读、收藏；窄屏与大字号可横向滑动。未读不再混入工具菜单。
- 点击分组按钮打开底部面板，换组保留阅读状态；面板可选择“显示本组全部”、新建/编辑分组及添加已有书籍。
- 收藏从完整书库读取，忽略分组和隐藏分组书籍偏好；换组不改变收藏列表。排序复用书架当前设置。
- 收藏是独立的 `Book.isFavorite` 属性，在书籍菜单及详情中操作；移动分组和更新书籍元数据不清除收藏。
- 新装未存储布局时默认为三列网格，已保存的网格/列表、列数、封面尺寸继续读取原字段。

## 兼容映射

- `settings/read` 仅注册一次；所有设置子页共用设置根页面作用域的 ViewModel。
- 旧字体路径显示字体与排版；旧手势路径显示翻页与手势。
- 旧导航路径显示应用设置；旧提醒路径显示目标与提醒；旧安全路径显示数据与隐私。
- TXT 旧路径继续有效，从书架的导入与文件进入。
- Room 10→11 仅新增 `books.isFavorite INTEGER NOT NULL DEFAULT 0`；既有表、索引、书籍、笔记和进度保留。
- 书籍备份增加可选 `isFavorite` 字段。旧备份缺字段时，新恢复书籍未收藏，覆盖已有书籍保留当前收藏。
- 新增 `app_visual_style` 偏好，缺失时使用清简蓝，用户选择后持久保存；所有旧偏好键及旧导航字段保留。
- 分页窗口、预加载、进度写入及 ReaderViewModel 保存竞态保护保持原实现。
- 应用设置同步预览最新阅读选择，保存请求串行写入；当前代次成功并获存储确认后才解除预览保护。保存失败显示提示并允许重复选择重试。

## 0.3.0 品牌与开书排版

应用名称为页间，保留原 applicationId 与偏好。章节排版缓存由应用级单例提供，完整结果写入可清理的本机缓存；仅颜色／夜间变化复用结果，改变几何排版设置使缓存失效。首份保存偏好就绪后才准备开书内容；当前请求页先显示，未完成结果不写临时页数与比例。

## 0.3.1 操作反馈与返回

书签保存成功后显示提示，当前位置已有书签时顶栏图标为实心；失败提示不覆盖正文。提示避开阅读底部控件。书架历史菜单准确标为“阅读历史”，直接续读仍通过已有书籍进入。涉及阅读器的导航取消两个页面叠加过渡，其他页面沿用原动画；异步进度/统计保存与排版缓存保留。

## 0.3.2 默认封面

清简蓝的无真实封面回退使用无字水墨山景底图，左上排版实际书名与作者。两张底图按书名固定选择，暖纸墨韵原回退不改。真实封面优先；现有圆角、大小、书架布局与应用/阅读配色不改，未新增设置选项。网格长短书名统一预留两行，百分比和菜单在下方同一行对齐；字号、菜单回调及列表布局保留。

## 0.3.3 听书插件（历史，0.3.4 已撤下此流程）

设置 → 应用增加听书插件管理；阅读器右上耳机打开同一面板，未安装时提供 HTTPS 下载地址和本地 .yjp 导入，已安装时显示插件提供的播放控件。默认下载地址为空，不新增底部导航入口。
默认主包仅含稳定接口和适配器，不初始化系统 TTS。组件签名必须匹配基础 APK 发布证书，API v1、ID 和入口固定；验签后只读保存并加载，安装记录持久化。支持失败更新保护、相同包重复导入不打断、移除和重新安装；无额外 APK 安装权限。
夜间配色、原阅读偏好键、书籍数据与备份格式不变；插件属于本设备可重新获取的组件，不随书籍 JSON 备份迁移。正式换签需同步重签插件。

## 0.3.4 内置听书

设置 → 应用直接提供听书开关，默认关闭。独立偏好 speech_enabled 保存状态；开启不自动开始朗读，阅读器耳机入口仅开启后显示，关闭立即停止并释放语音。播放面板只有状态、语速、开始/暂停/继续、停止；缺少系统语音数据时给出安装入口。
听书实现静态包含在主 APK，无动态下载、导入、卸载或安装权限流程。保留已有 module 路径和原始语音接口，0.3.3 插件包仅为历史档案，不再参与运行；旧阅读设置、数据库及备份格式不改。


## 0.3.5 完整备份与听书兼容

完整 ZIP（yejian-library/1，schema 11）按文件流及逐条记录存储 15 个业务表、原书/正文包/封面/字体/背景与已知偏好；先在临时库和文件清单校验，再预览恢复。默认合并保留本机进度，收藏并集；替换要求显式确认。恢复设置默认不选；PIN/应用锁、目录授权、自动备份目录、来源 URI 与设备引擎不迁移。旧 JSON 为记录备份，仅合并并提示缺正文/定位。

自动备份默认关闭，在“数据与隐私”选择目录后开启，系统约每天、电量允许时执行；重启后打开应用重新注册。回读验证后记成功并只清理专用旧文件，保留 3/5/10 份，手动文件不清理。

听书开关独立共用分组；面板有短句播放、中文本地声音优先、错误码、当前/选择引擎、重新连接和系统设置。沿用系统 TTS，没有新增模型。iQOO 13 真机声音尚未验收。

## 0.3.6 搜索

书架顶部搜索为全库搜索，阅读器右上更多的全文搜索为书内底部面板。两者按同一规范原文字面匹配，支持单字与中文短语，无需 FTS5 或索引重建。显示批次进度，可取消，读取失败明确提示；全库分页加载，取消后可重试，旧任务不覆盖新查询。书内最多 100 个命中章；每章展示第一处及上下文，按真实布局跳转。原文读取绕过阅读 LRU，保留跨章预加载。

用户选定未来离线语音包方向；0.3.6 仍是系统 TTS，不新增尚未可用的离线开关或下载入口。新语音运行时/模型需后续接入与试听，总开关默认关闭。

## 0.3.7 离线语音模型

设置 → 应用的听书开关下方为“语音模型”；关闭听书时仍可下载和管理，试听须先开启。阅读器耳机面板提供同一入口。小雅/超文轻量包与 Kokoro 多音色包均不附带在 APK；下载源可切两个社区镜像和官方 GitHub，文件校验/解压/导入在应用内完成，不启动浏览器或另装 APK。

下载成功后选择使用，未下载不能选择；切系统语音后保留模型。删除选用模型先停止/释放、切系统语音，再删除；失败保留书籍和其他模型。支持语速及 Kokoro 中文音色，设置和模型独立保存于 noBackupFilesDir。关于页增加组件许可与来源。下载偏好不影响既有阅读设置键、数据库和书籍备份。

## 0.3.8 阅读可靠性修复

设置分类与顺序保留。语音模型页新增准备、试听、暂停和错误反馈，播放期间可停止试听；Kokoro 首段与分句处理使用同一模型数据和偏好，原模型保留。阅读计时按正文可见/生命周期结算，定期保存不延长空闲截止点；不自动清除或修正旧统计。共享导入与提示为一次消费事件，返回书架不再重播。名字待用户选定，本轮沿用页间。

## 0.3.10 运行与计时补充

设置目录和视觉不变。阅读参数仅更新实际订阅的控件与正文，不再通知完整应用外壳；主题、语言和锁配置仍即时生效。主导航保留各自状态；隐藏的统计页停止聚合，显示时后台刷新。

阅读统计按用户要求从新版重新记录，旧 version < 3 的统计首次开库移除，书籍/进度/笔记不清。前台正文有焦点才计时，停页持续累计，后台、锁屏、失焦暂停；每 5 秒及退出时保存。它是前台显示时间，保持亮屏停正文也计时；强杀或 I/O 故障可能丢最后未落盘增量。
