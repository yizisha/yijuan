# 一卷 0.3.12：EPUB 跳章与等待修复

日期：2026-10-27。版本：0.3.12 / 5709。

## 已确认的问题与修复

1. 分页窗口曾把已准备的章节直接拼接，允许“当前章、缺失的下一章、更后面的预取章”相邻。旧版回归要求从读序 1 到 2，实际到了 3。现在只连接包含当前章节的连续区间，缺章就先准备该章；真实空章按原入口呈现，不擅自越过。窗口调整时还校验当前布局键与章节页键一致，避免瞬时旧页号回写进度。
2. 目录跳转曾沿用该章上次停留的末页，以及同章待恢复的源位置。现在目录明确从章首打开，普通续读、搜索和书签仍保留各自精确定位。
3. 当前章节的新排版请求曾排队等待已无人等待的旧章或后台排版。现在取消同一本书的不匹配任务并优先处理当前请求，同一章的现成预取结果仍共享；快速返回不再复用正在取消的任务。
4. 已有完整 active revision 索引的 EPUB，打开时仍逐字扫描整书计算进度权重。现在复用导入时保存的 mainTextUnits；索引不完整、旧书或未 READY 时回退原正文计算，避免错用残缺或旧 revision 的索引。
5. 设置反序列化与书架实体映射移到 Default dispatcher，并合并尚未消费的旧状态。分页窗口、图片及标注指纹按实际输入缓存，减少控制面板更新时的重复工作。存储键和保存回调不变。

保留 UI、字体、色板、夜间、系列、PDF、模型与已有数据。Room 仍为 12，没有迁移、依赖或服务变更；不重解析用户书库，不再清零 version 3 阅读统计。
