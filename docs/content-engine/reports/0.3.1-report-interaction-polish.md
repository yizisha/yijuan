# 页间 0.3.1 / 5698 交互修正（2026-10-13）

## 改动与原因

- 阅读栏“字号”实际打开完整字体、排版、主题、翻页面板，现改为“设置”和共用细线齿轮图标。原设置面板、保存和快捷调节回调保留。
- 原书签保存后只更新列表，无成功反馈。现在仓库保存成功后显示“书签已添加”，当前阅读位置匹配书签时顶部图标为实心，并提供已有书签的无障碍说明。提示位于底部控件上方；未保存不显示成功。失败用提示告知原因，正文保持可读，不切到整页错误状态；取消保存不报失败或成功。已有书签仍可通过目录的书签标签查看/删除，重复添加行为保留。
- 原书架“继续阅读”菜单实际调用阅读历史导航，现准确显示“阅读历史”，仍在顶部管理菜单。已有阅读记录的书籍继续按原直接续读设置打开，未新增首页装饰卡。
- “未读”由工具菜单归入首页阅读状态行：当前分组／未读／正在读／已读／收藏。宽度根据字号扩展，窄屏和大字号允许横向滑动，48dp 触控与选中状态保留。网格、列表共用相同组件，原分组/排序/全库收藏计算不改。
- 原 NavHost 对两个页面同时淡入淡出并轻移，返回时主导航会先于阅读页面卸载而恢复、改变内容尺寸，存在正文叠加及运动残留的条件。现在只要导航两端包含阅读器，进出均无页面叠加动画；主导航还会等待 visibleEntries 中的阅读器退出，避免先挤压正文。其他页面保留原过渡。取消/离开分页作用域与既有异步进度/统计保存继续使用原实现，未清空正文缓存。
