## 已确认原因与修复

1. 分页段落长按更新 `selectionState`，界面却读取另一个始终为空的 `localSelection`，无法绘制选区或显示菜单。现已统一状态；新增实际长按复制用例在修复前明确失败，RED XML 独立保留。
2. 滚动模式没有向 `CrossBlockSelectionModel` 登记段落显示长度，`beginAt` 拒绝未知段落。现在跟随段落生命周期登记／注销；分页正文也共享本页模型与坐标注册表，实现同页跨段选择。
3. 选区变化曾作为 `pointerInput` 键，引发重组时取消正在拖动的手势；另一处理器可能在初次长按抬手时清除新选区。改用稳定键和最新状态，并仅在按下前已有选区时处理清除。
4. 开始／结束手柄分别移动对应边界，正向与反向选择保持另一端不动；多个段落仅由末个被选段落显示菜单。
5. 菜单原先混用了窗口像素、dp 数值和估计宽度。现在通过 `PopupPositionProvider` 使用实际测量大小定位、限制在窗口内，拖动手柄时不会因点击菜单外而立即清空选区。分页在选区存在时暂停翻页，清除后恢复。
6. 新增“写笔记”：编辑前固定所选摘录与源范围，确认后调用已有注释仓库保存，取消不保存。弹窗采用与阅读明暗匹配的完整语义主题，输入控件与禁用保存状态可辨认。单段注释在启动异步保存前固定章节，跨段提交携带自己的章节与权威范围。
7. 分页高亮按与当前片段相交筛选，避免跨段／跨片段的已有注释在渲染时漏掉。

没有新增依赖、数据库结构、备份字段或偏好键。注释模型本来包含 `note`；已有实体转换与笔记订阅继续使用。
此次不修改分页测量、章节预加载、连续分页窗口、阅读进度或阅读设置保存机制；仅在选区活动期间协调翻页手势。
