## 视觉和行为

按用户确认的范围完成首页／书架、阅读、笔记、统计与设置。采用暖纸色、墨色文字、鼠尾草绿、铜色细节与中文宋体标题；深色界面采用炭黑与暖金。

- 书架：山水横幅展示最近阅读的真实书籍，直接续读；没有近期书籍时提供导入入口。笔记、书单、统计、发现连接已有功能。保留列表／网格、分组、状态筛选、长按多选和书籍菜单。横幅高度随长标题自适应。
- 封面：保留书籍原始封面加载；自动书封采用宋体、书脊、柔和纸色与山水装饰。
- 阅读：纸白与夜黑配色温暖化；章节标题区增加淡山水，不增加正文测量高度。内置“宋体 / 衬线”使用本地字体，导入字体及其他字体选择继续生效。
- 阅读面板：夜间主题使用炭黑、奶油文字和暖金；新增夜间切换、真实窗口亮度、恢复系统亮度、字号和行距快捷控件。四个详细设置入口保留。所有阅读偏好仍通过原有即时更新和延迟保存链路。
- 笔记：纸质卡片、来源书封、宋体摘录及淡色高亮。搜索、按书过滤、打开原文、删除和导出继续使用已有数据链路。
- 统计：主趋势图跟随周／月／年所选窗口，补齐没有阅读的日期，年视图按月合计。检查截图时确认数据库提供秒，而总时长大字曾按毫秒除算，已改为秒；测试样例 312 分钟正确显示为 5 小时 12 分钟，日均 44 分钟。原有最近七天趋势、累计统计和热力图保留。
- 设置：山水品牌横幅与独立纸质菜单卡片，使用已有分类与跳转回调。

阅读字体、应用主题来源、书架视图和列数均沿用用户已有选择。要获得参考图的宋体正文，可在阅读设置中选“宋体 / 衬线”，浅色阅读主题选“纸白”；应用品牌配色仍从“外观 → 墨韵雅致”选择。
