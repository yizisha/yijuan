# 一卷 0.3.13：旧页面回写与切章目标保护

日期：2026-10-28。版本：0.3.13 / 5710。当前为本地修复，原书真机复验尚未完成。

## 问题与修复

先前真机已确认 0.3.12 在《巧遇之后》第 7→8 章、目录第 8/9 章仍停旧章，见[失败记录](0.3.12-device-check-2026-10-28.md)。本轮没有查看或复制原书正文，使用匿名合成长章节及导航状态测试诊断。

确认两处相关缺陷：

1. `ReaderScreen` 的 `uiState` 是 Compose 委托状态。在延迟页面回调里读取 `uiState.scrollRequestVersion`，读取的是回调执行时的最新状态，而不是创建旧阅读页面时的编号。编译前字节码也显示：调用 `onPagedPageVisible` 前临时读取 State 和请求编号，允许旧页携带新编号回写。
2. 导航层只校验请求编号和书籍/章节身份，没有保证手动指定的新章先被显示。新增测试先请求第 2 个章节，再投递带当前编号的第 1 个旧章节回调，旧版实际退回第 1 章，断言 `expected 1 but was 0` 失败。这条路径能够复现“新目标被旧页覆盖”。

修复：每棵阅读页面创建时复制不可变的 `renderRequestVersion`，用于分页/滚动的位置和落页回调；手动切章发布新状态前，记录该请求的目标章，只有目标章的首个有效页面回调可以解除进入保护。解除后允许正常连续翻页及反向返回。书签、搜索及正常续读的存储格式不变。

没有修改分页算法、预加载窗口、排版缓存大小、主题或设置结构；Room 仍 12，不清库、不重解析、不重置阅读时长，也没有新依赖或服务。
