# 一卷 0.3.11：系列整理、PDF 与文件大小

日期：2026-10-24。版本：0.3.11 / 5708。

## 功能与入口

- 书架顶部更多 → 系列与卷序；书籍详情提供同一入口。手动命名系列、选择成员、上下移动排列、重命名或移出。没有自动猜测文件名，也没有新增推荐内容。
- 同系列在网格和列表中合并展示。先应用原有分组、阅读状态和收藏筛选，再合并；收藏不会被其它未收藏卷带入。卡片卷数表示当前筛选匹配的成员，主动打开面板可查看整个系列。
- 到达本卷末尾提示打开下一卷，不强制跳转；卷序变化、移出与删除实时更新下一卷。下一本有阅读记录时沿用其自己的位置。
- PDF 使用已有 Android PdfRenderer，从内部可随机访问的副本渲染；后台串行处理，每次只持有当前页，不预渲染整本。保留原始页面颜色，界面继续沿用主题。
- PDF 支持点按/横向拖动翻页、双击与双指缩放和平移、公共目录/滑杆跳页、页码恢复与区域标注。渲染失败显示重试，单页限制最多 400 万像素。
- PDF 拖动距离按每次手势独立计算；点击、拖动与缩放由同一个原生手势处理器接收，切页时保留完整的触摸流，避免分散监听和重建导致的偶发漏翻页。回归使用连续三次往返，而非只确认一次成功。
- 所有书籍详情展示文件大小。优先使用实际导入副本长度，旧记录进入详情时补测；缺文件显示未知。漫画归档保留原文件大小，不将应用缓存、模型计入书籍体积。

## 数据与兼容

用户已明确同意 Room 11→12 增量迁移。仅新增 `books.seriesName TEXT`、`books.seriesOrder INTEGER NOT NULL DEFAULT 0` 与系列索引，不重建书库。普通元数据、阅读进度和重新解析不能抹掉系列及收藏状态。

排序验证成员集合并在事务内写入，过期列表失败不会部分生效。每本书只属于一个系列；移动到另一系列会退出原系列。重命名不暗中合并已有同名系列。合并重复书籍可继承系列，冲突不自动推断，继承时追加卷序。

完整 ZIP 备份格式仍为 yejian-library/1，新快照包含 schema 12 系列字段；旧 schema 11 恢复补空系列与默认卷序。旧 JSON 兼容缺失的可选系列字段。旧版应用不保证能够读取新备份。

保留 0.3.10 的新统计 version 3，不再次清零。原首次开库清除 `<3` 历史统计的规则继续存在；书籍、笔记、书签及定位不随统计清理。

## 限制与未验收

- PDF 暂无 OCR、文字重排/复制、文本全文搜索、内嵌大纲解析及听书；正文排版设置不改变 PDF 原页内容。图片页不会因夜间模式强制反色。
- 手动卷序使用上下按钮，不是拖拽；没有自动识别系列归属。
- 截图检查发现英文窄屏筛选/翻页标签会省略，详情行的标签与数值间距偏紧；未将本轮视为全语言视觉验收。
- iQOO 13 尚未安装及触摸验收；双指触摸手感、宽屏、大字号与完整主题矩阵未验收。不能用模拟器耗时承诺真机流畅度。
- 既有主题、字体、封面、夜间配色及语音引擎保留；本轮没有新增依赖或服务，也未重新验证模型音质。
