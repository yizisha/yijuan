## 保存与阅读保护

此次未修改分页窗口、预加载、阅读进度写入及 `ReaderViewModel` 的 0.2.18 保存保护。
没有更改数据库结构、数据库版本、备份格式或阅读偏好键。

补查发现应用级 `SettingsViewModel` 原先仍等待存储回推才更新界面，快速改变不同阅读选项会基于旧值构造新请求。
新增用例在修复前明确失败：字号请求 23，界面仍为 18。
修复后同步预览最新请求，序列化不可变保存快照，只在当前代次保存成功且存储确认时解除保护；旧写入与其他应用偏好回推不会覆盖最新阅读选择。
同时验证保存中撤回到原值、恢复接收阅读器的外部更新、失败保留预览与相同选择重试，以及 ViewModel 重建后恢复。
失败会显示阅读设置保存提示。ViewModel 重建测试使用仓库流，不能等同于真实进程重启或磁盘持久化验收。
