## 实现

全库与书内搜索共用 `ChapterTextSearch`，按规范原文字面匹配，支持中文句中短语、单个字、英文忽略大小写，以及 `%_[]+*` 等符号，不依赖 FTS5、不解释查询为 SQL 或 FTS 表达式。标题和作者也使用字面匹配。每章展示第一次命中及前后摘要；真实 UTF-16 范围直接来自规范正文，摘要保留原标点并避免拆分代理对。

不再开书后台索引整本正文，也不再因书库变化重建全库索引。搜索按书 ID / 章号稳定排序，最多 32 章、约 256K 字符分批读取，超过预算的单个章仍单独完整读取；达到当前结果页后停止。新只读仓库方法绕过阅读 LRU，避免旧正文命中与挤占相邻章预加载。旧 FTS 工具与本机缓存文件保留，当前两条搜索入口不使用它们；兼容 `rebuildIndex` 入口为空操作。

全库每页 20 条，额外取一条确认还有下一页。新增进度、取消和重试；输入新词、离开页面及关闭书内面板取消旧任务。代次与协程取消检查阻止旧搜索/旧加载更多回写，失败不递增分页偏移，取消与读取失败不冒充“没有命中”。标题结果可先显示。书内面板与阅读设置采用相同底部面板形式，显示进度与错误，最多 100 个命中章节。

搜索带来的是库中章号，进入阅读器时先映射到目录读序；读取目标章校验，交给实际布局换算页码或滚动位置，避免空元数据退回章首、跳号章节错跳和源偏移被当作页码/像素。分页扣除剥离的章首回显，复用既有分页结果；滑动模式将窗口几何还原为滚动内容坐标，扣除阅读区顶部留白，命中文字完整可见。真实布局就绪前不以源字符偏移写临时阅读进度。

数据库仍为 Room 11，没有 schema、备份格式、阅读偏好键或主题变化。未修改分组/收藏/封面、听书实现及分页测量、排版缓存和相邻章预加载算法。

## 边界

- 搜索为分批原文扫描，不承诺整库瞬时返回；深度翻页会重新扫描前面的章节。单个超大章的读取/匹配仍受原仓库和设备限制，取消在协程检查点生效。
- 当前每章显示第一次命中；书内最多 100 个章节结果。未新增同章逐次命中、简繁混查、模糊搜索或 OCR。PDF 仍为页级阅读，未新增其行内定位。
- 重新解析后应重新搜索；跨查询分页期间同时删除/恢复/重解析可能改变结果集合，不宣称整个书库读期间是事务快照。隐藏 Markdown 等未显示文字的命中不等于可绘制的字符。
- ADB 末尾检测到 PD2408 / V2408A 手机及现有模拟器；本轮未安装新包、未清空数据、未操作它们或验收真机触摸。iQOO 13 上的覆盖升级、真实大书延迟、语音和系统文件目录仍待验证。截图并非真机证据。
