## 功能与入口

设置 → 应用 → 语音模型；开启听书后的耳机面板也可进入。默认保持系统语音，听书总开关仍默认关闭，升级保留已有开关值。模型下载完成后点击“使用”或“试听”；未开启听书时仍可管理模型。

| 模型 | 下载 | 解压占用 | 说明 |
|---|---:|---:|---|
| 小雅 INT8 | 13.4 MiB | 20.0 MiB | 单中文音色；模型卡标注训练数据限非商业用途 |
| 超文 INT8 | 13.4 MiB | 20.0 MiB | 不同中文音色；卡中数据集 CC0、基于小雅微调，不据此扩大整个模型授权 |
| Kokoro v1.1 INT8 | 140.2 MiB | 205.3 MiB | 中文音色 1–100，对应模型 sid 3–102；模型 Apache 2.0，附带资源各自许可 |

可选 ghfast.top、gh-proxy.com 两个社区镜像及 GitHub 官方源，应用内直接下载，不启动浏览器、不额外安装 TTS APK。支持进度、取消、切源重试、本地导入、试听、选择、删除及语速；Kokoro 可选中文音色。仅接受目录中固定的官方归档；本地导入也要求完全相同的文件及 SHA-256，不接受任意 ONNX 或旧 .yjp。

先校验归档，再受限解压到独占暂存目录；拒绝路径穿越、重复项、链接和特殊文件，核对解压大小。成功后移动目录，失败不替换工作模型；本机逐文件摘要在原生推理前复验。取消清理暂存，下一次下载清理已知命名的崩溃残留，保留其他文件。

语音包和模型选择位于 noBackupFilesDir，不进入书籍库、手动完整备份或系统迁移。删除选用模型先切系统语音，等待旧原生引擎释放后再删除。下载锁与语音偏好写入分开，下载期间语速保存不被阻塞。推理和释放共用单线程，旧代次不回写播放状态；面板关闭后暂停状态保留。

## 验证与限制

- **45 个不同定向用例 / 6 套件通过**；包括真实官方归档导入、重开/选择/删除、损坏/取消/失败保护、下载期间偏好保存、残留清理边界、解包约束、分句、原系统语音生命周期和原生 Compose 控件。最新批次覆盖先前失败用例，保留中间日志。
- **5 张原生 Compose 截图**，覆盖浅色、暖炭柔金夜间、听书设置、离线控件及 320dp / 1.6 倍字体的操作可达性。不是手机截图；两套全部主题/动态色及全部阅读内容未重复做全量验收。
- **隔离 Android x86_64 测试包 2 项通过**：实际 HTTPS 镜像下载、官方哈希/解压，以及真实 JNI 产生非零 PCM/WAV、播放启动与暂停/恢复/停止接口路径。日志 [run-09](0.3.7-test-results/android-native-run-09.log)。不等同于人工听到了声音或完整后台播放验收；暂停恢复测试覆盖接口链路，不据此宣称长时连续播放稳定。
- 三套模型均在桌面原生 1.13.8 引擎生成有效音频，数据见 [desktop-synthesis-check](0.3.7-test-results/desktop-synthesis-check.json)。Kokoro 在该电脑明显慢于轻量包，不据桌面结果推断 iQOO 性能，也没有主观音质优劣结论。
- 两个镜像的小雅归档在电脑完整下载并匹配官方 SHA-256；Android 测试实际使用 ghfast。其他模型镜像/不同运营商网络、断网或服务器长期可用性未逐项真机验收。
- 新增四个 ARM64 引擎原生库的 ELF PT_LOAD 段均为 16384 对齐；按 ABI 打包并压缩原生库，安装时 Android 解压，基础下载体积与安装占用不同。额外 ABI 可用 `-PspeechAbis=armeabi-v7a` / `x86_64` 单独构建，本轮只交付 ARM64；未做 release/R8 或全量测试。
- iQOO 13 没有覆盖安装此版、未实测听感/功耗/耳机与来电切换/锁屏长期朗读；保留现有章节起读行为，没有追加跨章服务、媒体通知或睡眠定时。
- Android 测试使用单独包名，未读写真实书库。测试后模拟器断开，ADB 导出原生 WAV 未完成，未在手机上安装测试包；隔离测试包的卸载留待模拟器重连，本轮未关闭/重建用户模拟器。桌面音频可在上方图库试听。
- 本轮不改 Room 11、书籍/备份格式、旧阅读设置键、主题/封面/收藏以及分页/进度/预加载代码；只编译直接依赖，测试按类/方法限定。未运行无关的全模块套件。

## 开发复验

真实归档集成用例通过 JVM 属性 `speech.fixture.dir` 指定测试夹具目录，需包含 `xiaoya.tar.bz2`、`chaowen.tar.bz2`、`kokoro-int8-multi-lang-v1_1.tar.bz2` 三份原始发布包。普通测试未配置这些大文件时显式跳过相关集成用例，不自动联网下载，也不在仓库/基础 APK 打包权重；本轮使用完整夹具，45 项均未跳过。隔离 Android 端测试只在 `-PspeechSmoke=true -PspeechAbis=x86_64` 构建的独立应用中运行。
