# 设置体系重构设计（树状图）

> 本文件保留旧阶段设计。0.2.20 已实施结构以 [当前设置与导航结构](../docs/SETTINGS_TREE.md) 为准，验证见 [统一 UI 报告](../docs/content-engine/reports/0.2.20-report-unified-ui.md)。

> 目标：消灭「同一件事在两个地方都能改」「阅读页设置和全局设置混着放」「一页堆十几项」三个问题。
> 原则：**全屏/半屏优先，弹窗只在一次确认或一次输入时使用**。

### 现状问题清单

| # | 问题 | 具体表现 |
|---|---|---|
| 1 | **字体两处可改** | 阅读页「排版 → 字体（含导入/清除/预览）」与全局「字体」页重复，且两处状态可能不同步 |
| 2 | **排版两处分散** | 阅读页有字号/行距/段距/边距/字数/对齐/缩进；全局「阅读」页只有一段文字说明，点进去是手势弹窗 |
| 3 | **手势两处分散** | 阅读页「翻页方式 → 翻页热区」与全局「阅读 → 手势自定义（弹窗）」是同一套配置的两个入口 |
| 4 | **色温/常亮/护眼 vs 提醒** | 都属于「阅读时的设备行为」，却一半在阅读页、一半在全局「提醒」 |
| 5 | **弹窗过载** | 手势是一个塞了 9 项的弹窗；目标值、PIN、标签、时间都各是一个弹窗 |
| 6 | **单页过长** | 书架页 7 项、TXT 页 7 项、数据页 6 项没有分组标题 |
| 7 | **关于页缺内容** | 只有版本 + 致谢，没有源仓库与更新日志 |

## 二、目标设计（重构后）

```
┌─ 阅读页内：底部半屏「阅读面板」（只放最高频 4 项 + 一个入口）
│   ├─ 字号 A- ──●──── A+          （即时生效，不跳页）
│   ├─ 亮度 ────●────             （系统亮度快捷条）
│   ├─ 主题：19 色板横向滑动选择
│   ├─ 翻页：模式 / 动画 两个胶囊
│   └─ 更多设置 → 直接进入「设置 → 阅读」（同一个 Composable，复用）
│
└─ 全局设置（一级列表 → 全屏二级 → 需要时半屏三级）
    ├─ 1. 阅读                      ← 阅读器的一切默认值（唯一入口）
    │   ├─ 1.1 排版
    │   │   ├─ 字号 / 行间距 / 段间距 / 首行缩进
    │   │   ├─ 页边距 / 每行字数 / 对齐方式
    │   │   └─ 简繁转换
    │   ├─ 1.2 字体                  ← 从原「字体」页整体迁入
    │   │   ├─ 内置字体（11 款，带预览）
    │   │   ├─ 导入字体（ttf/otf）+ 清除
    │   │   └─ 字体预览卡
    │   ├─ 1.3 翻页
    │   │   ├─ 翻页模式（上下滑动 / 左右翻页 / 无动画）
    │   │   ├─ 翻页动画（滑动 / 覆盖）
    │   │   ├─ 音量键翻页
    │   │   └─ 翻页热区（左右对称 / 左手 / 右手 / 自定义宽度）
    │   ├─ 1.4 手势                  ← 原弹窗改为整页，分组呈现
    │   │   ├─ 点击：左 / 中 / 右
    │   │   ├─ 滑动：左滑 / 右滑
    │   │   ├─ 双击：开关 + 动作
    │   │   └─ 长按：动作
    │   ├─ 1.5 主题与背景
    │   │   ├─ 阅读色板（19 套）
    │   │   ├─ 自动夜间（时段）+ 夜间色板
    │   │   ├─ 背景图片 / 纸质纹理 / 遮罩不透明度
    │   │   └─ 自定义背景色 / 文字色 / 恢复
    │   └─ 1.6 护眼与屏幕
    │       ├─ 保持屏幕常亮
    │       ├─ 护眼提醒间隔
    │       └─ 色温（滤蓝光）
    │
    ├─ 2. 书架
    │   ├─ 2.1 排布：网格/列表 · 每行本数 · 封面大小
    │   ├─ 2.2 分组：加入分组后不在「全部」显示
    │   ├─ 2.3 点击行为：已读书籍直接进入阅读页
    │   └─ 2.4 自动扫描：选择目录 · 立即扫描 · 停止扫描
    │
    ├─ 3. 外观
    │   ├─ 主题模式（浅色 / 深色 / 跟随系统）
    │   ├─ 配色来源（品牌色 / 跟随壁纸）
    │   └─ 显示语言（9 种）
    │
    ├─ 4. 导航栏
    │   ├─ 显示「继续阅读」
    │   └─ 显示「统计」
    │
    ├─ 5. 阅读目标与提醒              ← 由原「提醒」页扩充
    │   ├─ 每日提醒开关
    │   ├─ 提醒时间（半屏时间选择器）
    │   ├─ 每日目标
    │   └─ 每周 / 每月目标（与统计页共用）
    │
    ├─ 6. TXT 导入规则                ← 分组标题化
    │   ├─ 6.1 净化：删除广告行 · 合并空行 · 自定义替换
    │   └─ 6.2 分章：自定义正则 · 只用自定义正则
    │
    ├─ 7. 数据
    │   ├─ 7.1 备份与恢复
    │   ├─ 7.2 导出书架（CSV / JSON）
    │   └─ 7.3 局域网传输
    │
    ├─ 8. 安全
    │   └─ 应用锁 · 设置/清除 PIN
    │
    └─ 9. 关于
        ├─ 9.1 源仓库（本项目 fork 自 HuZaiGong/flowreader + 本仓库地址）
        ├─ 9.2 更新日志（按版本倒序列出每次优化的内容）
        └─ 9.3 开源许可 / 致谢

### 迁移映射（旧 → 新）

| 旧位置 | 新位置 |
|---|---|
| 阅读页「排版 → 字体 / 导入 / 清除 / 预览」 | **1.2 字体**（唯一入口） |
| 阅读页「排版 → 字号…简繁转换」 | **1.1 排版** |
| 阅读页「翻页方式 → 翻页模式/动画/音量键」 | **1.3 翻页** |
| 阅读页「翻页方式 → 翻页热区」+ 全局「阅读 → 手势自定义」 | **1.4 手势**（合并） |
| 阅读页「阅读主题」全部 | **1.5 主题与背景** |
| 阅读页「护眼与屏幕」全部 | **1.6 护眼与屏幕** |
| 全局「字体」页 | 删除（并入 1.2） |
| 全局「阅读」页 | 删除（并入 1.1 / 1.4） |
| 全局「提醒」页 | **5 阅读目标与提醒**（补时间选择器 + 周/月目标） |
| 全局「导航」页 | **4 导航栏** |
| 书架 / TXT / 数据 / 安全 / 外观 | 保留，补分组标题 |
| 关于页 | 补**源仓库**与**更新日志** |

### 交互规则（全批统一）

1. **半屏（ModalBottomSheet）**：阅读面板、章节目录、时间选择、目标值选择、书签/笔记列表。
2. **全屏二级页**：设置的所有二级页（统一 `SettingsDetailScaffold`：返回箭头 + 标题 + 分组小节标题）。
3. **弹窗（AlertDialog）只保留两类**：① 一次确认（删除、清除 PIN）；② 单字段输入（自定义正则/替换、PIN 输入）。
4. 手势、字体、标签这类**多字段编辑一律整页或 chip 编辑**，不再用一个大弹窗塞满。
5. 任何选项**只能有一个入口**；阅读页只提供快捷面板 + 「更多设置」跳转。
```

## 三、实施顺序

1. **第一批（本次已完成）**：不影响布局的缺陷与能力补齐
   - EPUB 目录跳转、EPUB 插图解析、分卷（`Chapter.volume` + 数据库 v8）
   - 音量键跨章、滑动模式侧边点击动画
   - 标签 chip 编辑、提醒时间选择器
2. **第二批**：按本设计树搬迁设置项（新增 1.1/1.2/1.3/1.4/1.5/1.6，删除「字体」「阅读」两个旧页，阅读面板改为快捷 4 项 + 更多）
3. **第三批**：统计页（周/月/年）与书籍详情页（字数 + 二级页）重构，关于页（源仓库 + 更新日志）
