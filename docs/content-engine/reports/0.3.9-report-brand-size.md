## 55.2 MiB 的实际组成

基于已交付的 0.3.8 ARM64 APK（57,871,398 字节），读取 ZIP 条目的 `compress_size`，下表为**安装包中压缩后的占用**，不是安装后空间或模型下载大小。机器记录见 [apk-size-baseline.json](0.3.9-test-results/apk-size-baseline.json)。

| 类别 | 压缩后占用 | 说明 |
|---|---:|---|
| DEX 代码 | 27.62 MiB | 当前 debug 未开启 R8，包含应用及依赖代码 |
| 原生库 | 12.33 MiB | 仅 ARM64，主要为 ONNX Runtime 与 sherpa-onnx |
| 字体 | 7.01 MiB | 其中 `reading_room_serif.otf` 6.88 MiB |
| 其他 res 资源 | 6.28 MiB | 两张水墨缺省封面合计 4.85 MiB；图标原图 1.24 MiB |
| 其他条目 | 1.55 MiB | 包括资源表等 |
| 其他 assets | 0.26 MiB | 不包含语音模型 |

取整及 ZIP 目录等开销使分类之和与文件总长略有差异。基础 APK 没有 `.onnx` 模型、语音模型归档或 `voices.bin`；下载后的模型是另外的本机占用。

## 判断与建议顺序

对以本地阅读为主的应用，当前包有明显的精简空间；不能把全部体积归因于听书模型，也不能把 55.2 MiB 当成安装后总空间。

1. **优先测量现有 release/R8 配置**：目前交付 debug APK；项目已有 release 的代码和资源裁剪配置。本轮不切换交付类型。后续先构建比较，再验证原生 JNI、反射、备份、开书和听书路径；通过前不替换已验证安装包。不得预先承诺精简后的具体体积。
2. **优化已有图片的编码与分辨率**：两张封面和图标原图值得检查，保持现有视觉效果与原始设计。需要对照截图，不能仅为缩包替换用户喜欢的界面。
3. **评估字体**：先检查覆盖、重复与实际使用；中文字体子集可能漏字，不能直接删除或只留常用字。按需下载需要另做离线回退和已有选择兼容设计。
4. **最后再评估引擎拆分**：离线语音原生库占 12.33 MiB，但模型已经按需下载。暂不恢复之前不可用的下载代码插件方案，也不删除听书功能。

本轮只改名并分析体积，没有执行代码裁剪、字体下载化或依赖移除。
