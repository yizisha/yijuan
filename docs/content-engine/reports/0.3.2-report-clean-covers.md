# 页间 0.3.2 / 5699 默认封面改造（2026-10-13）

替换清简蓝的无真实封面回退：浅纸底、水墨远山／楼阁、左上书名与作者及细分隔。沿用现有圆角、封面尺寸；根据书名确定两张底图之一，无随机闪变。作者从现有参数读取，不在图里写死。

用户随后补充长短书名造成进度和三个点错位的问题：网格书名现统一预留两行（minLines = maxLines = 2），并用当前字体实测中英文混合两行字形得到相同的槽位高度；百分比和菜单同处下方的一行并垂直居中。同一行书籍底部对齐，长标题仍省略；高度随系统字号而非硬编码像素适配。默认及紧凑分支共用布局，保留原有对应字体大小。网格里两套主题都受此对齐修复影响，暖纸封面绘制本身不变；列表布局不改。最初只设 minLines 时，大字号的单行与真实两行高度仍相差 18px；增加实测槽位后几何断言通过，初次失败证据保留。

暖纸墨韵的原封面分支、真实封面 File / Coil 加载分支没有修改。应用整体配色、夜间色板、分组／收藏／筛选、导航、设置入口、书签反馈、退出过渡、数据库／偏好、阅读排版／缓存／进度均保留。日夜切换不反转书籍纸面插画颜色，周围的夜间界面仍用原色板；动态和单色应用配色也不把书籍画作改成主题底色。
