## 已实现

默认主题为清简蓝，采用白色界面、中性灰容器、蓝色按钮与选中状态、系统标题字体和公共控件。参考图外部的蓝色展示背景不作为应用底色；取消容器的蓝色表面染色。暖纸墨韵保留暖纸灰绿、书卷标题与山水回退，使用同一套导航和布局。
应用及阅读夜间色板保留原值；纸白仅在清简蓝下调整为轻暖白，其他阅读色板、自定义背景与已保存字体继续生效。
新主题字段缺失时默认清简蓝，选择后写入 `app_visual_style`；连续切换及保存失败可恢复并重试。保存过的网格/列表、列数和封面尺寸继续读取。

书架导航为书架／统计／笔记／设置。首页不再显示继续阅读卡，已开始的书按既有偏好直接续读，历史与导入、布局、排序、分组管理归更多菜单。
主筛选为当前分组／正在读／已读／收藏，点击分组进入底部面板，换组保留状态，并可选择显示本组全部；未读保留在更多菜单。
收藏从完整书库读取，忽略当前分组和隐藏分组书籍偏好。网格、列表和详情可收藏/取消，修改元数据、移动分组和更新进度不会覆盖收藏；重复书籍合并保留任一已有收藏。

阅读控制包含听书、书签、细线进度条、目录、夜间、亮度、字号和更多，进度展示真实章节计数及阅读百分比。
阅读设置采用字体／排版／主题／翻页标签，屏幕与护眼归更多阅读设置；编辑组件复用应用设置实现。
目录、书签、笔记统一在标签面板，分别进入对应标签，保留跳转、编辑及删除确认。笔记页增加编辑入口、笔记/划线标签及随标签导出，详情、搜索、统计与主要设置使用公共主题。
仅呈现已有功能，未添加评分、WebDAV、定时关闭或推荐书单。

## 参考图逐页收敛

参考图的浅蓝色是海报外部背景。应用采用白色页面、深灰文字、中性灰容器，蓝色用于选中和交互；日间正文维持轻暖白，夜间沿用原有暖炭柔金。

| 界面 | 本轮落实 |
|---|---|
| 网格 / 列表书架 | 三列紧凑网格、较小的书名与进度、细线书籍菜单；列表缩减行间留白；筛选底块缩小，触控区域保留 |
| 导航 | 共用细线书架、统计、笔记、设置图标，取消大块导航选中胶囊，保留颜色和字重区分 |
| 阅读日间 / 夜间 | 返回、听书、书签、目录、日夜、亮度、字号、更多采用统一线条；正文字体、配色和分页逻辑继续读取既有设置 |
| 阅读设置 | 短下划线标签；逐行字号、字体、行距、段距、边距、色板与夜间；亮度、字体导入折叠；自定义数值在主动选择预设前保留 |
| 目录 / 书签 / 笔记 | 返回和搜索收进标签头；搜索与批量展开按需显示；当前章节使用左侧色条和浅选中底色，去掉无意义的宽占位 |
| 笔记 / 划线 | 双标签、窄色标、摘录和批注、真实来源与日期；编辑、删除及回原文收入菜单；导出跟随当前标签 |
| 详情 | 减少封面区二次内边距，保持真实封面、作者、简介与阅读信息，按钮采用统一圆角 |
| 导入 | 文件、目录扫描设置及 ZIP 三个现有入口使用分类色块和细线箭头，没有添加新的导入服务 |
| 全局设置 / 主题预览 | 五类目录保持原结构；柔和功能色块与细分隔线，阅读纸页预览读取实际配色和已选字体；动态 / 单色使用各自语义颜色 |
| 统计 / 搜索 | 公共标题、文字尺度、选项控件和细线图标同步调整，既有图表与搜索结果保留 |

新增 [FlowIcons](../../../core/src/main/java/com/flowreader/app/core/designsystem/component/FlowIcons.kt) 统一原生矢量线宽，图标随分辨率缩放、主题变色，无需外部图片生成。真实封面始终优先；清简蓝缺失封面采用中性文字封面，暖纸仍保留山水回退。图库包含参考图及 9 张调整前截图入口。截图为测试内容，不借用概念图书籍和评分冒充用户数据。

## 数据与关键接口

- Room **10→11**：仅新增 `books.isFavorite INTEGER NOT NULL DEFAULT 0`，无破坏性重建。真实旧 schema、索引、书籍、笔记与进度通过迁移测试；另验证收藏关闭数据库再打开后保留。
- `Book.isFavorite`、`BookEntity.isFavorite` 默认 false；`BookRepository.setFavorite` 使用定向 SQL，常规实体更新在事务内保留当前收藏。
- 备份书籍增加可选 `isFavorite`。新备份恢复标记；旧备份新恢复书籍未收藏，覆盖已有书籍保留当前标记。
- 原有偏好键、内容版本、阅读设置保存、连续分页窗口、预加载与进度算法保留。主题与收藏未新增依赖或外部服务。
