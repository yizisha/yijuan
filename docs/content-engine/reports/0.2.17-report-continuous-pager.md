# FlowReader 0.2.17：连续跨章分页

日期：2026-10-11。版本：**0.2.17 / versionCode 5690**。数据库保持 v10，未新增依赖。

用户反馈：0.2.16 的章节加载已经较快，但横向分页／点按翻页仍能感觉到章节边界。本批修改翻页结构，让相邻章参与同一段翻页动画。

## 原因和改动

此前章内翻页调用 `animateScrollToPage`，章末却调用 `goToNextChapter`。`scrollRequestVersion` 随导航递增，阅读屏幕重新创建分页器，即使命中缓存，视觉上仍是一次替换。

- **同一分页器跨章。** 将准备好的当前章、前一章、后续两章拼成连续页序列；稳定后的活动窗口至多 4 章。预备相邻页面 `beyondViewportPageCount = 1`。章节身份不再参与正常顺序阅读的分页器创建键；书籍、字体和页面几何等排版条件仍参与。
- **稳定页面身份。** 每页用章节读序与章内页码组成可保存的 String 键。添加前一章、淘汰远章时保留正在看的页面；窗口调整等待拖动／翻页结束。分页缓存 LRU 与活动窗口分开，已准备页不会因缓存清空而消失。
- **先完成动画，再更新状态。** 根据停止后的可见页键报告目标章和章内页码。`onPagedPageVisible` 采用已经准备好的正文、图片和标注，不请求再次加载、不改变 `scrollRequestVersion`。显式目录／书签跳转继续走原定位链路。冷边缘保留当前页，准备完成后沿用同一分页器动画。
- **每章各用自己的呈现数据。** 渲染使用该章图片 alt、标注、正文位移和批注；图片高度按页面尺寸缓存，并允许渲染与预排版安全读取。
- **统计与进度。** 跨章时重设章内页码的统计原点，向前跨章计一页，反向落到上一章末页不误计几十页。进度继续进入既有异步、有序保存链路。
- **覆盖动画修复。** `currentPage` 在动画半途变化，按它固定页面会使下一页提前跳到原点。改用页面实际横向偏移，下一页滑入到停稳。每页增加不透明背景，避免新旧标题穿透重叠。
