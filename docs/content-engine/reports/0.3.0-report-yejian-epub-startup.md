# 页间 0.3.0 / 5697 验证与交付（2026-10-12）

## 结果

- 名称改为“页间”，版本 0.3.0 / 5697。用户三本书图标接入自适应前景、奶油底色和单色轮廓；Android 8、14 原生资源加载与应用标签断言通过。包名仍为 `com.flowreader.app`。
- 上一章／下一章恢复到进度滑杆两侧，包含文字和方向箭头，48dp 触控区，首尾禁用。右下角更多及重复底部菜单删除；底部仅目录、日夜、亮度、字号。完整阅读设置进入唯一右上角菜单，原听书、书签、搜索、笔记、分享和专注入口可达。
- EPUB 排版采用应用级缓存、磁盘缓存、分批发布当前页和长段测量优化。启动先读取持久化排版设置，避免先用默认字体排一遍再重排。
- 128 个不同用例 / 12 套件最终全部通过，仅运行直接受影响用例。APK 构建、版本元数据、v2 签名、交付副本 SHA-256 一致性通过；13 张原生截图已检查。
- **未连接真机，未实际安装或执行用户设备升级。** 用户实际 EPUB、重启手机、真实触摸及厂商桌面/启动屏效果仍需手机验证；不以测试夹具代替真机结果。

## EPUB 等待原因与修复

1. 原分页缓存随 `ReaderScreen` 离开销毁。改由 Hilt 单例提供，RAM 保留 6 章；完整页在 IO 后台写入 `cacheDir/reader-pages-v1`。磁盘最多 32 项 / 16MiB，解压上限 32MiB，丢失或损坏时重新排版，不修改原书。
2. 原长段先测剩余全文，再从全文长度二分。长普通段落改为从 128 字指数探测，找到页内边界后精确二分；不把图片、标题等原子块拆开。10 万字单段用例断言首屏测量少于 2000 字、试探片段不超过 2048 字、总测量量少于正文 20 倍，并核对完整文本和坐标。
3. 当前请求页测好后先画出精确分页片段，后续页继续计算；完成之前不写虚假的页数与阅读比例。正式翻页窗口在整章完成后接管，保留原跨章窗口、预热和进度回调。
4. 开书等待第一份已保存设置，保留即时预览、串行保存及旧值回推保护；延迟偏好测试确认不会先发布默认排版。

缓存键包含书籍、章节、SHA-256 内容指纹、实际页尺寸、字体文件及排版属性、结构图片/标注、密度/字号缩放/locale/API。夜间、颜色及非几何设置不触发重排；表头实际范围参与标注指纹。磁盘使用 UTF-16 精确保留片段（含旧分页可能产生的半个代理项），不丢失源范围和块 ID。缓存格式为 v1，后续改变几何算法或字体资源需更新缓存格式/键。

首次打开、远距离跳章、排版设置变化或系统清理缓存后仍需准备当前页；本版不承诺所有 EPUB 零等待。后续页面未完成时预览仅供显示当前页，正式翻页与完整选择交互在完整结果接管后可用。
