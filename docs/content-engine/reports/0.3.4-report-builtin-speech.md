## 实现

- 将既有 :plugin:tts 模块改成普通 Android library 并静态链接进主 APK，保留目录路径以减少无关结构调整。TtsManager 直接构造系统语音实现，不再使用动态加载、下载、验签或安装指针；原 .yjp 文件和旧指针不读取也不删除。
- 新增独立 DataStore 偏好 speech_enabled，缺失时为 false。开启只保存标志，不自动开始朗读，也不创建语音引擎；打开耳机面板或显式起读时才初始化。关闭立即停止并释放，旧实例迟到回调无效。
- 保存串行化；失败显示反馈并保留原状态。真实 DataStore 写入、仓库重建后读回以及原阅读设置不被覆盖已验证，不能把仓库重建称为手机重启验收。
- 应用设置直接显示开关，阅读器耳机随开关显示/隐藏；关闭后原自定义听书手势也不能绕过开关。控制面板保留开始/暂停/继续、停止、语速与现有夜间配色，不含下载、导入、更新或移除表单。
- 继续使用手机系统 TTS；当前章长文本分段播放，避免拆开表情代理对。缺语言数据时给出提示、禁用播放，并提供系统语音数据安装入口；系统无对应处理页时回退手机设置。具体音色、语言数据与离线能力取决于系统引擎。
- 主程序原起读位置与章节行为保留；不新增自动跨章或定时关闭。数据库、旧阅读偏好键、备份 JSON、书架、主题、长按笔记、分页缓存和预加载算法未修改。
- 主 APK DEX 类定义核对确认包含 SystemSpeechPlugin，ZIP 内无 .yjp；TtsManager 源码无 DexClassLoader、HTTPS 下载或归档验证调用。旧归档验证 helper 与历史测试仍在仓库，但没有运行入口。
