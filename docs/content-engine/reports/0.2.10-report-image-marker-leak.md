# FlowReader — 0.2.10 报告（修复：插图下方泄漏出图片路径文字）

日期：2026-09-11。触发：用户装 0.2.9 后重新导入 EPUB，**插图能显示了**，但真机截图显示
插图下方多出好几行绝对路径文字：

    [IMG:/data/user/0/com.flowreader.app/files/books/5b8ba59a-89c5-4/8e1-935f-da1080c82817/
     revisions/8b993e1868d5ba7dfad8131ebc5f38bcd1f478…

即「内存里的图片标记被当成正文画了出来」。**这是 0.2.9 引入的缺陷**（0.2.9 之前渲染层
根本不消费结构图片，所以不可能出现这种泄漏）。版本 **0.2.10**（versionCode **5683**）。

---

## 1. 根因

图片块在排版里的文本是 `[IMG:<本机绝对路径>]`（内存标记，见 0.2.9 报告 3.6）。
`PagedReader.measureBlock` 只在**标记完整**（以 `]` 结尾）时才按图片尺寸测量：

    if (!isTitle && text.startsWith("[IMG:") && text.endsWith("]")) return imageBlockHeight(path)

而 `ChapterPaginator.paginate` 在「当前页剩余空间放不下这张图」时会走这一支：

    } else {
        val available = remainingHeight - gapPx
        val split = findSplit(text, indent, block.isTitle, available)   // 二分切分"文本"
        if (split > 0) { ...add(Fragment(text.substring(0, split)))... } // ← 切开的是图片标记
        flushPage()
    }

`findSplit` 对**被切开的**前缀（不以 `]` 结尾）不再命中图片分支，于是按**普通段落**测量 ——
一段 `[IMG:/data/...` 的"段落高度"很小，分页器便认为自己**成功**切出了一个片段，
而 `PageContent` 对这个片段同样不满足 `endsWith("]")`，于是走 `else` 分支当正文渲染。

⇒ 结论：**图片块被当成了可切分的文本**。只在"上一页剩余空间不够"时触发，
所以不是每张图都会看到（与截图一致：上图正常显示，下面的标记泄漏）。

> 同一缺陷对**旧书**的 `[IMG:]`（LegacyDocumentAdapter 路径）也存在，只是旧书没有结构图片，
> 只有在章节正文里真的带 `[IMG:]` 时才可能撞上。本批一并修好。

---

## 2. 修复

把「图片块如何测量」抽成**纯函数**并让被切开的标记报"永远放不下"：

    internal const val UNSPLITTABLE_IMAGE_HEIGHT_PX = Int.MAX_VALUE / 4

    internal fun measureImageAwareText(text, isTitle, imageHeightPx): Int? = when {
        isTitle -> null
        text.startsWith(IMAGE_MARKER_PREFIX) && text.endsWith("]") -> imageHeightPx(text)
        text.startsWith(IMAGE_MARKER_PREFIX) -> UNSPLITTABLE_IMAGE_HEIGHT_PX
        else -> null
    }

分页器的行为随之变为（已用测试锁定）：

1. 当前页放不下 → `findSplit` 对任何前缀都返回 0 → 不切分，直接 `flushPage`；
2. 换到新页后整块放入（图片高度本来就封顶一页高，必然放得下）；
3. **不会再有"半个标记"的片段**，正文里也就不可能画出路径。

---

## 3. 回归闸门（新增 4 项，都在 JVM）

| 测试 | 断言 |
|---|---|
| `completeImageMarkerIsMeasuredFromTheImage` | 完整标记 → 按图片高度 |
| `truncatedImageMarkerIsReportedAsUnfittable` | **被切开的标记 → 报"放不下"**（本次缺陷的直接闸门） |
| `theRuleLeavesPlainTextAndTitlesAlone` | 普通文本与章标题不受影响（不会把文本误判成图片） |
| `anImageThatDoesNotFitTheRemainingPageMovesWholeToTheNextPage` | 用真实 `ChapterPaginator` + 生产测量规则分页：图换页且**结果里不存在被切开的标记** |

第 4 项用的是与生产代码**同一条**测量规则（`measureImageAwareText`），
因此规则一旦被改回"把标记当文本"，它会立刻变红。
