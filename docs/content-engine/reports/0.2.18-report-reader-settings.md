# FlowReader 0.2.18：阅读设置切换修复

日期：2026-10-11。版本：**0.2.18 / versionCode 5691**。数据库 v10，未新增依赖。

用户已确认 0.2.17 连续跨章流畅无感，但发现上下滑动及翻页方式面板中的多数选项无法稳定切换。本批保留连续分页实现，修复设置保存竞态。

## 已复现根因

设置按钮先同步更新 ViewModel，350ms 后保存。阅读位置更新期间，`updateReadingWidgetSnapshot` 会修改同一个 DataStore 的小组件信息，`appSettings` 的 `map` 随之重新发出包含旧阅读偏好的 AppSettings。`loadSettings` 原先无条件覆盖 UI；延迟保存再读取 UI 时，也把旧值存回去。

回归用例先选择上下滑动、覆盖动画、右手热区和关闭音量键，再在保存前模拟小组件的旧设置回推。旧实现失败：期望 `pageMode=SLIDE`，实际恢复成 `PAGED`，其他选项同样恢复默认（RED）。

## 修复范围

- `ReaderViewModel.kt`：订阅时投影到阅读偏好并去重，避免无关 DataStore 写入影响界面；等待或正在保存本地偏好时保护最新选择。
- 延迟写入采用用户请求的不可变快照，连续选择重新计时，只保存最后一份请求；用保存代次保护新任务，避免旧任务取消后清除新选择。
- 保存成功后恢复外部偏好同步；保存失败显示提示、释放待保存状态并允许再次选择重试。护眼计时器仅在间隔变化时重建。
- 两个既有测试文件补充回归。构建版本、设置更新日志、HANDOFF 和安装说明同步为 0.2.18。
- 本批未修改 PagedReader 的连续跨章结构或跨阅读模式的位置换算算法。
