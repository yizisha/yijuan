# 0.2.23 柔和标注与文件位置验证报告

构建日期：2026-10-12。版本 **0.2.23 / 5696**。[安装包](../../../01_最新安装包_APK/心流阅读器-v0.2.23-柔和标注与文件位置.apk) · [原生截图](0.2.23-annotation-location-preview/index.html) · [去重用例](0.2.23-test-results/summary.json)。

## 改动与入口

- 正文标注默认细下划线，随正文颜色适配日间与夜间；阅读面板“主题”及应用设置“阅读 → 主题与背景”均可选择柔和高亮。荧光黄色改为低饱和墨色，22% 不透明度。显式 UNDERLINE 数据始终划线。
- 只叠加文字样式，保留原标注类型、颜色、源范围及笔记；markdown、缩进、多段不连续范围继续使用原坐标映射。长按操作栏根据显示偏好显示“划线”或“高亮”，保存回调不改变。
- 书籍详情的统计／目录／书签／笔记容器末尾新增“文件位置”。原文件、私有阅读副本及另存副本分别展示，可选中和复制位置。
- 新导入保存原 URI；旧书可用系统选择器关联原文件，关联只记来源，不覆盖正文、进度或笔记。ZIP 私有解压文件不冒充来源。
- 原目录优先尝试兼容的文件管理器；无处理器或目录授权不足时，回退到带原文档初始 URI 的系统文件浏览器。主共享存储可显示实际路径，其他提供方保留 URI，避免伪造路径。
- 私有副本不能让普通文件管理器直接进入，可通过系统“另存”生成本地副本。导出写入失败不改变阅读副本或先前成功的另存记录，并提示可能留下未完成目标文件。
- `annotation_display_style` 是新独立偏好；本设备来源索引在 `book_file_sources.xml`，不改变 Room 11、书籍 JSON 备份和旧偏好键。来源记录排除云备份与设备转移，不把本机授权当作其他设备授权。
- 保留现有主题、夜间配色、连续分页、预加载与阅读进度，不新增依赖、外部服务、全盘权限或 FileProvider 可访问根目录。

## 限制与设备验收

**本轮无连接设备，真机安装、覆盖升级、重启、触摸与系统文件管理器定位尚未完成。** Robolectric 的 Intent 与剪贴板验证不能代替厂商文件管理器。URI 提供方可忽略初始位置，文件迁移／删除或授权失效后应重新关联；不保证所有机型直接选中该文件。旧版未保存原来源，无法自动逆推出原目录。ZIP 原压缩包目录未自动回溯，可手动关联或另存。

本批仅调整文字正文标注，不改变 PDF 区域标注渲染；历史 Gate G5、表格对齐和自动跨页扩选边界保留。原长按笔记等直接受影响路径已回归，磁盘上用户真实数据库未修改。
